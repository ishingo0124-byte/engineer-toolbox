# 収益化の設計 — エンジニアの道具箱

## 収入源（段1）

| 源 | 仕組み | 見込み単価 | オーナー作業 |
|---|---|---|---|
| Google AdSense | ツール直下＋ページ下部の2枠（`build.py` の `ad_slot`）。config.json に client ID を入れるだけで有効化 | 技術系は RPM ¥200〜500 前後（1,000PV あたり）。月10万PVで ¥2〜5万 | AdSense 申請（審査 数日〜2週間）。審査は「ツール15本＋about＋privacy」が揃ってから |
| Amazon アソシエイト | 解説末尾に関連技術書を1冊（PR表記） | 紹介料 2〜3% | 申請（180日以内に3件の売上が必要。無ければ再申請） |
| ASP（A8.net / もしもアフィリエイト） | 学習サービス（Udemy・技術スクール）、VPS/クラウド（さくら・ConoHa・Xserver）。**インフラ系ツールの読者と相性が良い** | 1件 ¥500〜1万 | 登録（サイト URL が要る → 公開後） |
| Cloudflare Web Analytics | 収入ではないが、どのツールに需要があるかを知る唯一の材料 | — | トークンを config.json に |

## 広告の置き方（体験を壊さない）

- ツール本体の**上**には置かない（初速で結果を見せる）。ツール直下と記事末尾の2か所のみ。
- アフィリンクは `{{aff:key}}` で解説に1〜2本。関係ない商品を貼らない。`rel="sponsored"`＋「PR」表記。
- 収益より **再訪** を優先（ブックマークされるツールは広告収入が安定する）。

## 段2（有料製品）の判断基準

Analytics で **月 3,000 PV 超のツールが3つ**出た時点で、そのカテゴリの「Pro 版」を検討する。
候補:ブラウザ拡張（Chrome Web Store、¥300〜1,000 買い切り or 月額）、Windows 小物ツール、まとめ PDF（BOOTH）。
決済は Stripe / Lemon Squeezy / BOOTH（オーナー登録）。
