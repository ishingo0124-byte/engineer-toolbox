# 公開手順（オーナー向け・初回のみ 30〜40分）

コストは **ドメイン代 年 ¥1,000〜2,000 のみ**。ホスティングは無料枠。

## 推奨構成:GitHub + Cloudflare Pages

1. **GitHub アカウント**（無い場合のみ作成。既にあれば省略）→ 新規リポジトリ `engineer-toolbox`（Public/Private どちらでも可）。
2. **Cloudflare アカウント**（無料）→ 「Workers & Pages」→「Pages」→「Git に接続」→ 上のリポジトリを選択。
   - ビルド設定:フレームワーク「None」／ビルドコマンド `python site/build.py`／出力ディレクトリ `site/dist`／環境変数 `PYTHON_VERSION=3.12`。
   - Python の `markdown` が必要なので、リポジトリ直下に `requirements.txt`（同梱済み）を置いておく。Cloudflare Pages は `requirements.txt` を自動でインストールする。
3. **ドメイン**:Cloudflare Registrar で `.com`/`.jp`/`.dev` など取得（年 ¥1,000〜2,000）→ Pages の「カスタムドメイン」に追加。候補は `docs/00_戦略.md` の「名前」参照。
4. `site/config.json` の `base_url` を本番 URL に変えてコミット（会社側でやる。オーナーは URL を教えるだけ）。
5. 公開後:
   - **Google Search Console** にサイトを登録し、`sitemap.xml` を送信（10分）。
   - **Cloudflare Web Analytics** を有効化し、トークンを config.json に（5分）。
   - 15本以上公開して2週間ほど経ったら **AdSense** を申請。

## 代替:GitHub Pages だけ（Cloudflare 不要）

リポジトリの Settings → Pages → Source「GitHub Actions」。同梱の `.github/workflows/pages.yml` がプッシュのたびに `python site/build.py` を実行して公開する。
独自ドメインは GitHub Pages のカスタムドメイン設定で。

## 以後の更新の流れ（オーナー作業なし）

会社側が `site/tools/` にツールを追加 → `git push` → 自動ビルド・自動公開。
※ `git push` の認証は初回のみオーナー（`gh auth login` または GitHub Desktop でサインイン）。
