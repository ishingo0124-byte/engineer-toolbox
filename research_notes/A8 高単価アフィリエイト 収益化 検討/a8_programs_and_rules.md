## Q1. A8.net で1件あたりの報酬が高いカテゴリはどれか（カテゴリ別の報酬額・成果条件・承認率・制約）

### Takeaway
2026年10月の A8 公式「高額報酬ランキング」で1件1万円を超えるのは、主に次の5群:
- 転職エージェントの「面談」成果（1万〜7.8万円）
- 証券口座の「登録＋1回取引」（1万〜2万円）
- 保険・貯蓄の無料相談の「面談」成果（1万〜1.4万円）
- 不動産（投資面談・査定・空室対策で3万〜8.27万円）
- 光回線の「開通」（auひかりで1万〜3万円）

加えて、スクール・講座の受講開始（1万〜5万円）、美容医療／GLP-1（1万〜3.8万円）、パーソナルジム（1.5万〜3万円）も高い。
いずれも成果地点は「面談・開通・取引・契約」と重い。承認率（確定率）は公開ページに出ておらず、外部ブログが引用した値は68〜100%だった。

## Q2. 小さなサイト・新しいサイトでの提携審査の仕組みと、特別単価

### Takeaway
A8 の会員登録そのものに審査はない。審査は、プログラムごとに広告主がサイトや SNS を見て行う。期間は即日から数週間以上で、即時承認のプログラムもある。
審査基準と否認理由は公開 FAQ に書かれていない。短期間に大量の提携を申請すること自体が禁止事項になっている。
特別単価（特単）の公式な申請手順は公開されていない。担当者（専属担当）を通じた交渉で決まるもので、その担当は回答者の約6割にまだ付いていない。

### Cited Findings
**会員登録と審査の流れ**
- 「A8.netによる入会時の審査はございません。」 登録すると「【A8.net】メディア会員募集プログラム」へ自動で提携申請される。そのプログラムで否認されても会員としては使い続けられる。スタッフが定期的にサイトを巡回していて、違反があれば警告メールか即時退会になる — [A8 FAQ: メディア会員になるための審査はありますか](https://support.a8.net/a8/as/faq/2007/07/as.html)
- 提携審査は「広告主が自社のプログラムに提携申請があったメディア会員のWebサイトやブログ、SNSに対し、そのプログラムの広告素材の利用にふさわしいかどうかを判断する審査」とされる — [A8 FAQ: 広告主によるメディア会員の審査とは](https://support.a8.net/a8/as/faq/2014/08/as_2.html)
  - 期間は「即日から数週間以上掛かるケースもあり、広告主により異なります」。「プログラムによっては即時承認される場合もあります」
  - 結果は各広告主からメールで届く。否認理由が開示されるかどうかは書かれていない
- 規約・禁止事項で、次の行為が禁止されている — [A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php):
  - 短期間に無差別に大量の提携を申請すること
  - 登録していないサイト・アプリ・メール・SNS への掲載
- 規約上、メディアサイト名・メディアID・氏名・サイトURL が広告主に開示されることがある — [A8 メディア会員利用規約](https://www.a8.net/compliance/media-userpolicy.php)

**資格要件（禁止事項ページ）**
- 次の場合は会員資格がない、または掲載・登録を取り消されうる — [A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php):
  - サイト管理者が18歳未満
  - 登録情報が虚偽
  - 特定の人しか見られないサイト
  - 自分で管理していないサイト（オークションページや動画共有のページなど）
  - アダルトサイト、公序良俗に反するサイト
  - 理解できない言語のサイト、著作権を侵害するサイト

**広告主側の確認手段（ステマ規制以降）**
- 2023年12月から、広告主はメディアが提出した「広告掲載URL」をプログラムごとに CSV でダウンロードして確認できるようになった — [ファンコミュニケーションズ「景品表示法の指定告示および対応方針について」(最終更新2023年12月)](https://support.a8.net/ec/news/202308_01.pdf)
  - PR表記に不備があれば修正を依頼し、改善しなければ「提携解除をご検討ください」と広告主に案内している
  - 提携前のメディアについては、登録サイトURL（「アピールサイト」）を見て審査できる

**特別単価と専属担当**
- 公開 FAQ の「プログラム提携について」1ページ目に、特別単価の項目はなかった。2・3ページ目は未確認 — [A8 FAQ プログラム提携について](https://support.a8.net/a8/as/faq/04/)
- 協会調査2026（回答 n=991）より — [意識調査2026 PDF](https://affiliate-marketing.jp/release/202606.pdf):
  - 収入が増えた理由に「単価・条件の向上: 特別単価の適用、報酬単価の引き上げ」「担当者がついたことによる案件提案や相談」が挙がっている
  - 専属担当に求めることは「特別報酬の交渉力」41.9%、「クローズド案件の紹介」31.4%
  - 専属担当が「現在、ついていない」という回答は「6割を切った」
  - 自由記述には、特単交渉の進み具合の共有や「専属担当がつく基準の明確化」を求める声がある
- 利用者レビューには「成果を挙げると特別単価も貰いやすい」とある（個人の感想） — [ITreview A8.net レビュー（検索結果の要約）](https://www.itreview.jp/products/a8/reviews/233194)

**ASP ごとの評価の違い（協会調査2026、満足度1位に選んだ理由）**
- A8:「広告数が多い」49.9%、「管理画面が使いやすい」31.9%、「他のASPより報酬単価が高い」11.0%
- レントラックス: 単価が高い 39.2%、専属担当の対応が良い 57.6%
- Felmat: 単価が高い 39.6%、専属担当 72.6%
- TCSアフィリエイト: 単価が高い 38.9%、専属担当 66.7%
- — [意識調査2026 PDF](https://affiliate-marketing.jp/release/202606.pdf)
- バリューコマースは広告主の審査が厳しく、アクセストレードは登録自体に審査がある、という記述がある — [hinakira 591選](https://hinakira.com/list-of-affiliate-high-paying-projects/)

### Inferences
- 新しい小さなサイトでも A8 には登録できる。ただし高単価の金融・転職・不動産は、広告主が登録サイトURL と広告掲載URL を見て判断する。申請前に次を揃えておくべき:
  - 運営者情報
  - プライバシーポリシー
  - PR表記
  - その分野の記事・ツールが実際にあること
- Claude Code に提携申請を任せる場合、「短期間での無差別な大量申請」は規約違反になる。申請は人が選んだプログラムだけに絞り、数日に分けて出すのが安全。
- 特単は、成果を出して専属担当が付いてから交渉する流れが一般的と読める。成果ゼロの段階で特単を前提にした収益計画は立てられない。
- 単価そのものは、レントラックス・Felmat などの「担当者型」ASP が評価されている。A8 は「最初の入口、案件数、セルフバック」に使い、成果が出た案件だけ他の ASP と単価を比べる、という使い分けが合理的と推定される。

### Gaps
- 広告主の提携審査で、PV・記事数・運営者情報などの具体的な基準を A8 が公開している資料は見つからなかった。
- 否認理由が開示されるか、再申請できるかは、公開 FAQ に記載がなかった。
- 特別単価の正式な申請窓口・条件の公式説明は見つからなかった。

## Q3. A8.net 公式ルール（規約・禁止事項・否認・支払い・税・AI・SNS・ステマ）

### Takeaway
最新の規約は2026年9月1日改訂版。自己申込・自己クリック・他人名義・複数アカウント・ボット・虚偽表示・未登録媒体への掲載・DM での送付・会員限定情報の公開は禁止で、違反すれば報酬没収や強制退会になりうる。
支払いは「月末締め・翌々月15日払い」で、1,000円以上なら振り込まれる。振込手数料はメディア負担（ゆうちょ66円〜他行660円）。報酬は税込で、確定した報酬は失効しない。
PR表記は規約上の義務になっている。AI 生成・自動投稿について明文の規定はないが、ボットによる成果やクリックは禁止されている。

  - SNS アカウントは、事前にメインサイトまたはサブサイトとして登録が必要
  - リンクは「SNS・note用」タブから作る
- 「SNSのDM機能など外部に公開されていない場所への掲載は禁止行為」 — [A8 FAQ: DMでアフィリエイトリンクを送ることは可能ですか](https://support.a8.net/a8/as/faq/2023/post_2095.html)
- 広告素材の改変、広告主名を使った SNS アカウント、公式アカウントへのなりすましは禁止 — [A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php)
- LINE は上記の許可リストに含まれていない（Q3 の Gaps 参照）。
- メールでの配信は、登録した媒体であれば可能と読める。未承諾の広告メールは禁止 — [A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php)

**ステマ規制（PR表記）**
- 規約上、メディアには「『PR』等の表記の実施」が義務づけられている。表記はユーザーが広告と認識できる「分かりやすい位置」に置く — [A8 メディア会員利用規約](https://www.a8.net/compliance/media-userpolicy.php)
- A8 の対応方針 — [ファンコミュニケーションズ ステマ規制 対応方針 PDF](https://support.a8.net/ec/news/202308_01.pdf):
  - 2023年8月末から、全メディア会員に PR表記を要請している
  - 消費者庁に確認したところ「PR等の表記が不要である具体的な事例は明言されておりません」。このため「原則として全てのメディア会員様へPR等の表記をお願いする方針」
  - 表記のポイントは「認識しやすい位置（視野に最初に入る画面内など）・文字の大きさ・文字の色」（消費者庁の指針から引用）

**規模（参考）**
- A8.net トップページ（2026年10月18日現在）: 広告主数（累計）27,422社、登録サイト数 3,738,232、稼働中の広告プログラム 4,472 — [A8.net トップ](https://www.a8.net/)
- プレスリリース（2026-06-30）: 広告主は累計約27,000社以上、アフィリエイトメディアは約366万（2026年5月時点） — [PR TIMES 2026-06-30](https://prtimes.jp/main/html/rd/p/000000226.000026953.html)

### Inferences
- このプロジェクトは「根拠・確認日」をページに載せる方針だが、A8 の報酬額や広告主の条件をそのまま載せると「会員限定情報の公開」禁止に触れるおそれがある。ツールページに書くのは、商品の公開情報（公式サイトの料金など）までにとどめるべき。
- 支払いの考え方:
  - 1,000円以上なら翌々月に振り込まれる。他行口座だと毎回495円引かれる
  - 月数千円の規模では、ゆうちょ口座（66円）が実質的に最も有利
  - 「2年間成果ゼロ」が強制退会の事由になりうるため、休眠させないことも大事
- 免税事業者（課税売上1,000万円以下）のままでも、A8 の報酬は減らされないと読める。なお、2026年10月以降に仕入税額控除の経過措置の割合が変わるが、それについて A8 は言及していない（Gaps 参照）。
- Claude Code による自動化で気をつける点:
  - ボットによるクリック・アクセスで成果やクリックを生むことは禁止
  - 自動で SNS 投稿すること自体に明文の禁止はない。ただし投稿先は登録済みで公開されたアカウントに限られ、DM は禁止
  - 広告コードや素材は改変できない
  - AI 生成の記事を禁じる明文はない。ただし「事実と異なる情報」での宣伝は禁止で、薄い量産記事への業界の目は厳しい

### Gaps
- 規約本文の条番号つきの全文と、改訂の差分（2026-09-01 改訂で何が変わったか）は確認できなかった（要約の範囲のみ）。
- 2026年10月の経過措置の変更（控除割合が80%から70%などへ。出典によって記述が食い違う）を受けて、A8 が免税事業者の報酬を扱いを変えるかどうかは、公式情報が見つからなかった。
- LINE（公式アカウント・オープンチャット）やメールマガジンへの掲載について、公式 FAQ の回答本文は確認できなかった（カテゴリの存在のみ確認）。
- 即時支払サービスの手数料は確認できなかった（FAQ カテゴリ /a8/as/faq/10/ があることのみ確認）。

## Q4. アフィリエイターの収入分布の公開データ（収入ゼロ／月1,000円未満／月100万円以上の割合）

### Takeaway
NPO法人アフィリエイトマーケティング協会の2026年調査（n=991）では、月収が「収入はない」28.7%、「1,000円未満」10.6%で、**合わせて39.3%が月1,000円未満**、**52.8%が月1万円未満**。一方で月100万円以上は19.2%（500万円以上だけで11.7%）いた。
この上位層は法人と長期運営者に偏っていて（協会は「法人の割合が増加していると推測」）、時間もかけている。500万円以上の78.4%が1日3時間以上を費やしている。
市場規模は、矢野経済研究所の推計で2025年度4,598億円の見込み（前年度比+5.0%）。

- このプロジェクトの見通し（6か月で月1,000円〜1万円）は、この調査の下位50%（月1万円未満）の層に当たり、現実的な置き方。
- 月100万円以上の層は、5年以上の運営・毎日3時間以上の作業・法人である割合が高い。「オーナーの手をほぼ使わない」運営で到達するのは難しい、というのが調査データからの推論。
- 「AI による回答で完結するゼロクリック」が減収の理由の上位にある。作業が完結するツールは AI に置き換えられにくく、そこに比較優位があると考えられる（推論）。

## Q5. セルフバックとは何か。オーナー自身が使える高単価案件は何か

### Takeaway
セルフバックは、A8 会員が自分で申し込んだり購入したりして報酬を受け取れる会員限定のサービス。通常の自己アフィリエイトは禁止されているが、その例外にあたる。
2026年10月時点の高単価の例:
- クレジットカード: キャンペーン中なら1件1万〜1.45万円、法人カードは最大23,038円
- 証券: DMM が1万円
- 銀行: 最大1万円

オーナーが実際に使ってみることは、レビューの一次情報にもなる。ただし金融商品は、収入目的で申し込むと与信履歴に影響するので注意。

### Cited Findings
**仕組み**
- セルフバックは「A8.net会員限定サービス」 — [A8 セルフバック説明](https://www.a8.net/about_selfback.html)
  - 手順: セルフバック画面で商品を選び、成果報酬と成果条件を確認してから、「セルフバックを行う」ボタンで広告主のページへ進む
  - 報酬は購入の「数時間後」に管理画面に反映される
  - 成果報酬は1,000円から振り込める
  - 入会金・年会費は0円
  - 成果条件の例は「WEB購入後、30日以内の入金確認」
- セルフバック以外での自己申込・重複申込・テスト注文・他人名義での申込は禁止事項 — [A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php)
- 規約にもセルフバックを例外として定めた条文はない。「注文の意図がないと疑われる行為の禁止」「同一のアプリケーションの繰り返しのインストール」の禁止はある — [A8 メディア会員利用規約](https://www.a8.net/compliance/media-userpolicy.php)

- セルフバック全体の案件数と、証券・FX・保険・光回線のセルフバックの現行額（2026年10月時点）は、ログインしないと見られないため未確認。
