500GB のSSDを買ったのに、OSでは465GBしかない。
「1k」は1000なのか1024なのか、毎回あやふやになる。
μ やナノ、ピコの桁も、言われるたびに数え直している。
数値と接頭辞を入れると、SI接頭辞20種とIEC接頭辞8種のすべてに換算し、工学表記と指数表記も並べて見られます。

## 使い方

1. 「数値」に値を入れ、「入力値の接頭辞」から、その数値に付いている接頭辞（k、M、Gi など）を選びます。接頭辞のない数値なら「接頭辞なし・10⁰」です。
2. 「単位」は表示用の記号（B、Hz、V など）で、空欄でも動きます。入れると、表の値の後ろに「kB」「GiB」のように付きます。
3. 上段に、接頭辞を外した基準値、工学表記、指数表記が出ます。

ここまでが換算の本体で、次は表の読み方です。

4. その下に、SI接頭辞（y〜Y）の表と、IEC接頭辞（Ki〜Yi）の表が並びます。どちらも、入力した量を各接頭辞で表したときの値です。
5. 一番下の早見表で、容量・メモリ・回線速度・周波数が、10進と2進のどちらで扱われるかを確認できます。

## 仕組み・計算式

換算は、いったん接頭辞を外した基準値に直してから、各接頭辞で割るだけです。

```
基準値 = 入力値 × 基数^指数   （SIは基数10、IECは基数1024）
表の値 = 基準値 ÷ 基数^指数
```

SI接頭辞は、国際度量衡局（BIPM）の「国際単位系（SI）文書」（SI Brochure）が定めています。キロ（10³）、ミリ（10⁻³）のように、すべて10のべき乗です。このツールの対象は、ヨクト（10⁻²⁴）からヨタ（10²⁴）までの20種で、2022年に追加されたロナ（10²⁷）・クエタ（10³⁰）などは入っていません。

IEC接頭辞のKi（キビ）、Mi（メビ）、Gi（ギビ）などは、IEC 80000-13（旧 IEC 60027-2）が情報量のために定めたもので、1024のべき乗です。名前は似ていますが、基数が別の体系です。

2種類の表記の差は、桁が上がるほど開きます。1024^n ÷ 1000^n を計算すると、次のとおりです。

- k と Ki: 約2.4%
- M と Mi: 約4.86%（ここまでは「誤差」と言える大きさです）
- G と Gi: 約7.37%
- T と Ti: 約9.95%

差はそれぞれ「Kiのほうが大きい」向きです。容量が大きいほど、公称値とOS表示の食い違いが目立つ理由はここにあります。

工学表記は、指数が3の倍数になるように直した形です。指数表記（科学的表記）は、仮数部を1以上10未満にそろえた形です。

## 計算例

数字は、script.js の換算・表示ロジックを node で実行して確かめました。

**例1: 500GB のSSDは、OSで何GiBに見えるか**

数値に 500、接頭辞に G（10⁹）を選びます。基準値は 5e+11（5×10¹¹）で、IEC表の Gi の行は 465.6612873 になりました。MiB の行は 476837.1582 です。

OSが2進で計算して「GB」と書く場合、465GB台に見えるのはこのためです。故障ではありません。

**例2: 1 TB は何 TiB か**

1 に T を選ぶと、Ti の行は 0.9094947018、Gi の行は 931.3225746 でした。1TBのドライブが「931GB」と表示されるのは、この計算どおりです。

**例3: 1 Gi は G でいくつか**

1 に Gi を選ぶと、基準値は 1073741824、SI表の G の行は 1.073741824 です。工学表記は 1.07374×10^9（有効数字6桁）、指数表記は 1.073742×10^9 でした。

**例4: 境界値（0.01 と 0 と 大きな数）**

0.01（センチなら 1 c）の工学表記は 10×10^-3 です。仮数部が1以上1000未満になる形なので、「0.01」は「10ミリ」の形で出ます。0を入れると「0×10^0」です。

1 Y を入れると、基準値は 1e+24 のように表示されます。大きな数や小さな数は、このように指数つきで出ます。

## よくある間違い

### 1. 回線速度を2進で割ってしまう

Mbps、Gbps は10進です。1 Gbps = 1,000,000,000 bit/s で、バイトにすると 125,000,000 B/s（125 MB/s）。これを 1,048,576 で割って約119.2 としてしまうと、MiB/s の話になります。どちらで話しているかを、先に確認してください。

### 2. bit と byte の換算までできると思う

このツールは接頭辞の換算だけです。単位欄は表示用の文字で、「Mb」を入れても「MB」には変わりません。ビットとバイトの変換は、8で割る計算が別に要ります。

### 3. 「1,000」や「1e3」と入力してエラーになる

数値欄は、桁区切りのカンマも指数も受け付けません（試すと「数値を入力してください」のエラーになりました）。1000 と書くか、接頭辞で桁を指定してください。

### 4. kB と KB と kiB を混ぜる

SI接頭辞のキロは小文字の k です。大文字の K は、接頭辞として定義されていません。実務では「KB」と書いて1024を意味する資料もありますが、決まりがあるわけではありません。正直なところ、資料を読むたびに「これはどっちだろう」と確認しています。

## よくある質問

### Q. どの接頭辞を選べばいいか分かりません。
A. 迷ったら、元の資料の表記をそのまま選んでください。小文字 k、M、G ならSI（10進）、Ki、Mi、Gi ならIEC（2進）です。

### Q. センチやデシは、どうして工学表記に出てこないのですか？
A. 工学表記は指数を3の倍数にそろえる形式だからです。センチ（10⁻²）やデシ（10⁻¹）は、SIの接頭辞ですが3の倍数の列にありません。表には載っています。

### Q. 有効数字は何桁ですか？
A. JavaScript の倍精度浮動小数点数で計算するので、内部では15桁前後です。表の値は10桁、工学表記は6桁、指数表記は7桁に丸めて表示します。
