## 使い方

1. 上の欄に変換したい単語・識別子を1行に1つずつ入力します。
2. 「下のリストで使用」する出力形式（camelCase・snake_caseなど）を選ぶと、各行の変換結果と検出された入力形式が一覧表示されます。
3. 「選択形式を全行まとめてコピー」で改行区切りのテキストとしてコピーできます。
4. 下の一括変換表では、入力した全行を7形式（camelCase・PascalCase・snake_case・kebab-case・CONSTANT_CASE・Title Case・dot.case）で同時に確認できます。

## 仕組み・単語分割の判定基準

このツールはまず入力行を区切り文字（スペース・`_`・`-`・`.`）で分割し、さらに各かたまりを「小文字→大文字」の境界（例: `apiResponse`の`i`→`R`）と「大文字の連続（頭字語）→大文字+小文字」の境界（例: `HTTPServer`の`P`→`Se`の手前で区切り、`HTTP`をひとかたまりとして扱う）、数字と英字の境界で単語に分割します。この頭字語の扱いは、多くのコード整形ツール（ESLintの`camelcase`ルールや、C#の.NET命名ガイドラインが定める2文字を超える頭字語のパスカルケース化など）で採用されている一般的な方式です。英数字と区切り記号だけで構成された行だけを分割対象にし、日本語など対象外の文字を含む行はデータを欠落させないよう塊のまま扱います。

出力形式はそれぞれ次のように単語を結合します。camelCase（先頭の単語のみ小文字化、以降は先頭大文字）、PascalCase（全単語の先頭を大文字化）、snake_case（すべて小文字＋`_`区切り、Pythonの命名規約PEP 8で関数・変数名に使用）、kebab-case（すべて小文字＋`-`区切り、CSSのクラス名やURLパスで一般的）、CONSTANT_CASE（すべて大文字＋`_`区切り、多くの言語で定数名に使用）、Title Case（各単語の先頭を大文字化しスペース区切り）、dot.case（すべて小文字＋`.`区切り、設定キーなどで使用）。

**現場の落とし穴**: 頭字語（ID・URL・HTTPなど）をPascalCase/camelCaseにする際、このツールは`Id`・`Url`・`Http`のように先頭だけ大文字にする方式で統一しています。しかし言語やスタイルガイドによっては2文字の頭字語（`ID`など）は大文字のまま保持するのが慣習という例もあり（Go言語の公式スタイルガイドEffective Goは`ID`や`URL`など頭字語は大文字のまま保つことを推奨）、機械的な変換結果をそのまま採用せず、プロジェクトの命名規約と照らし合わせて確認することをおすすめします。

## 言語別の命名慣習の早見表

| 言語・領域 | 変数・関数 | 定数 | クラス・型 |
| --- | --- | --- | --- |
| JavaScript/TypeScript | camelCase | CONSTANT_CASE | PascalCase |
| Python（PEP 8） | snake_case | CONSTANT_CASE | PascalCase |
| Go（Effective Go） | camelCase（頭字語は大文字保持） | CamelCase（大文字始まりでexport） | PascalCase |
| Ruby | snake_case | CONSTANT_CASE | PascalCase |
| CSS | kebab-case | kebab-case（カスタムプロパティ等） | - |
| DB（テーブル・カラム名） | snake_case が主流（PostgreSQL/MySQL等） | - | - |

## よくある質問

### Q. 数字が単語の途中にある場合はどう扱われますか？
A. 英字と数字の境界で別の単語として切り出します。例えば`version2Update`は`["version","2","Update"]`に分割され、snake_caseでは`version_2_update`になります。

### Q. 入力形式が「混在／判定不可」と表示されるのはどんな時ですか？
A. 区切り文字（`_` `-` `.` スペース）と大文字小文字の境界が両方混在している、または一般的な命名パターンのどれにも一致しない場合に表示されます。分割や変換自体は行われます。

### Q. すでにスペース区切りの文章を変換できますか？
A. できます。スペースも区切り文字として認識するため、`already Title Case Words`のような文章もそのまま各形式に変換されます。
