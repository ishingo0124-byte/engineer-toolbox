Excelからコピーした表を README に貼りたい。
パイプとハイフンを手で打つのは面倒だし、日本語が入ると縦線がずれる。
前に書いた表も、列が増えて崩れたままだ。
CSV・TSV・スペース区切りのデータ、または崩れたMarkdown表を貼ると、全角文字の幅を考えて桁をそろえたMarkdown表になり、逆変換のCSVも同時に出ます。

## 使い方

1. 上の欄にデータを貼ります。1行目が見出し行になります。Excel やスプレッドシートからコピーしたものは、タブ区切りで入るので、そのまま貼れます。
2. 区切り文字は「自動判定」のままで構いません。うまくいかないときだけ、カンマ・タブ・連続スペースから選びます。
3. 「列の配置」に、左から順に l（左）、c（中央）、r（右）をカンマ区切りで入れます。空欄の列は、既定のままです。

配置欄の動き方は、次の「仕組み」で詳しく書きます。ここだけ少しクセがあります。

4. 「Markdown表」の欄の内容をコピーして、README やブログに貼ります。同じ内容をCSVにしたものが、下の欄に出ています。

## 仕組み・計算式

入力がMarkdown表かどうかは、2行目以降に区切り行（`-`、`:`、`|`、空白だけの行）があるかで判定します。区切り行の書き方は GitHub Flavored Markdown（GFM）仕様の表（tables 拡張）に従っています。その1行前に `|` があれば、Markdown表として読みます。どちらでもなければ、CSV/TSV/スペース区切りとして扱います。

区切り文字の自動判定は、タブが1つでも含まれればタブ、なければカンマが1つでも含まれればカンマ、どちらもなければ連続スペースです。CSV は、ダブルクォートで囲んだカンマや、`""` で表した引用符も読めます。

列幅は文字ごとの表示幅で決めます。半角は1、全角は2です。幅2とみなす範囲は、Unicode の East Asian Width（UAX #11）で Wide・Fullwidth とされる主な領域です。ひらがな、カタカナ、CJK統合漢字、ハングル、全角記号、絵文字がここに入ります。

```
列幅 = max(3, 見出しの幅, 各セルの幅の最大値)
空白の数 = 列幅 − セルの幅
```

区切り行の書き方は、配置で決まります。

- 左揃え: `:---`
- 中央揃え: `:--:`
- 右揃え: `---:`
- 指定なし: `---`（GFMの既定）

どれも `-` の数は、列幅に合わせて調整されます。

セル内の `|` は `\|` にして出力します。CSVに戻すときは、元の `|` に戻します。

## 計算例

出力は、script.js の変換ロジックを node で実行して確かめました。

**例1: 初期表示の入力（配置 l,c,r）**

```
| 名前     |    役職    | 経験年数 |
| :------- | :--------: | -------: |
| 田中太郎 | エンジニア |        5 |
| 佐藤花子 | デザイナー |       12 |
| Lee      |     PM     |        3 |
```

「田中太郎」（幅8）と「Lee」（幅3）が同じ列に入っても、右の縦線はそろっています。

**例2: 崩れた表の整形**

`| a | b |`、`|:-|-:|`、`| 1 | 2 |`、`| 3 |` の4行を貼り、配置欄を空にすると、区切り行から左・右揃えが読み取られ、足りない列が空セルで埋まります。結果の最終行は `| 3   |     |` で、CSVは `3,` になりました。

**例3: セルにカンマと縦線が入る場合**

`A,"x,y"` と `B,a|b` を貼ると、Markdown側は `x,y` と `a\|b`、CSV側は `"x,y"` と `a|b` になりました。

**例4: 境界値（見出しより長いデータ行）**

`a,b` の次の行が `1,2,3` のとき、見出しに空の3列目が追加されます。CSVは `a,b,` と `1,2,3` です。データの列数が多いほうに、全体がそろえられます。

## よくある間違い

### 1. 貼った表の配置が無視される

最初から入っている配置欄の `l,c,r` が、貼った表の区切り行より優先されます。右揃えの列が左揃えに変わって驚きました。元の配置を残したいなら、配置欄を空にします。

### 2. 空白を含む値をスペース区切りにする

「山田 太郎」のように値の中に空白があると、スペース区切りでは2つのセルに分かれます。例4のように、見出しにない余分な列ができてしまいます。住所や氏名があるデータは、タブかカンマで貼ってください。

### 3. 桁がそろっているのに、プレビューでずれる

整形したはずなのに、見た目が変わらない。そんな経験はありませんか？

整形のために入れた空白は、Markdownレンダラーでは無視されます。ソースを読みやすくする整形で、表示結果が変わるわけではありません。表示のずれは、配置指定か、区切り行の列数の不一致を疑ってください。

### 4. 記号や絵文字で、桁がずれる

幅2として数えるのは、上の範囲だけです。★ や → は、このツールでは幅1です。フォントによっては、これらが全角幅で表示されます。ソースで縦線がずれて見えたら、記号の幅を疑ってください。

## よくある質問

### Q. 列の配置を指定しないと、どうなりますか？
A. 配置欄が空のとき、貼った表に配置があればそれを引き継ぎます。CSVなどからの変換で指定がなければ、`---` になります。GFMでは既定の配置で、多くの環境で左揃えに表示されます。

### Q. Markdown表をCSVにするだけの使い方もできますか？
A. できます。表を貼ると、下のCSV欄に出ます。セルの `\|` は `|` に戻り、カンマや改行を含むセルは引用符で囲まれます。

### Q. 見出しだけの表は作れますか？
A. 作れます。`a,b` だけを貼ると、見出しと区切り行だけが出力されました。
