生成コマンド

tar -czvf backup.tar.gz src/ README.md

展開後・作成後の確認コマンド

tar -tzvf backup.tar.gz

生成された条件の意味

    落とし穴: tar は c（作成）・x（展開）・t（一覧）のうち1つしか同時に指定できません。-zxvf のように短いオプションをまとめて書く場合、f は直後にファイル名を取るため必ず最後に置く必要があります（-fzxv のように途中に置くと、次の文字がファイル名として解釈されエラーになります）。zip はファイル名の文字コードを保存する仕様が実装によって異なり、Windows で作成した日本語ファイル名入り zip を Linux の unzip で開く、あるいはその逆を行うと文字化けすることがあります。
