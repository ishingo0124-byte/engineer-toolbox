find . -type f

生成された条件の意味

    落とし穴: -delete は式の中で最後に置かないと、そこで即座に削除が実行されてしまい後続の条件（-name や -type など）が効きません（find は式を左から評価し、-delete 自体が真を返すため）。-mtime +7 は「7日より新しい/古い」の境界を1日分丸めるため実際には「8日以上前」を意味します（find(1) の仕様）。ファイル名にスペースが含まれる場合は -print0 | xargs -0（NUL区切り）または -exec CMD {} \; を使うと単語分割で壊れません。

    GNU find と BSD/macOS find の違い: GNU findutils は -printf・-regextype・-samefile などの拡張を持つが、macOS 標準の BSD find には無い（Homebrew の findutils を gfind として入れると GNU 版を使える）。GNU find は起点パス省略時にカレントディレクトリを補うが、BSD find は起点パスの省略を許さない実装がある。-iname と -delete はいずれも現行の GNU/BSD 双方で利用可能。
