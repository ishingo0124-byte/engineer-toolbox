友達とマイクラを遊ぶのに、サーバーは何GB借りればいいのか。
パルワールドは重いと聞くけれど、本当に16GBも要るのか。
プラン表を見ても、その数字の根拠がどこにも書いていない。
このツールは、ゲームと人数を入れると、公式ページとレンタル各社の公開ページに書かれたメモリの数字だけを出典つきで並べ、上限を満たす最小のプランも出します。

## 使い方

1. 「ゲームの種類」を選びます。Java版のバニラ、Java版のMODあり、統合版（Bedrock）、パルワールドの4つです。
2. 「同時に遊ぶ人数」を入れます。登録している人数ではなく、同じ時間にサーバーへ入っている人数です。
3. 上の枠に、出典の最小値から最大値までの範囲が出ます。その下の表で、どのページに何人で何GBと書いてあったかを確認します。
4. 一番下に、目安の上限を満たすプランのメモリ容量が、ロリポップ! for Gamers・XServer GAMEs・ConoHa for GAME ごとに並びます。

ここまでが操作のすべてです。人数を1人ずつ変えると、表の行が入れ替わるのが見えます。

## 仕組み・計算式

このツールに計算式はありません。メモリの数字はすべて、公開されているページに書かれた値をそのまま表にしています。係数を掛けたり、人数から割り算で出したりはしていません。

使った出典は次のとおりです。

- Mojang「Minecraft Bedrock 版のサーバーをダウンロード」のシステム要件（RAM は 4 GB）
- ポケットペアの「Palworld Server Guide」の要件ページ（バージョン 1.0.4。メモリは 16GB、安定した動作のためには 32GB 以上を推奨）
- ロリポップ! for Gamers の解説記事（マイクラの人数別の表と、パルワールドの人数別の表）
- XServer GAMEs の Minecraft と Palworld のプラン表、メモリ割り当ての解説記事
- ConoHa for GAME のマイクラ解説記事（4人以下は 2GB、5〜10人は 4GB、11人以上は 8GB）

どの行にも確認日（2026年10月27日）を付けています。

数字の出ていない場面は、無理に埋めずに「公開された目安がありません」と出します。たとえば、MODの数や、モッドパックの大きさごとのGB数を載せているページは、確認した範囲ではありませんでした。ですからMODありの場合は、人数別の表と「MOD・プラグインを入れるなら最低4GB程度」という注意書きだけを並べています。

この数字が見ていないものもあります。プラグインの種類、描画距離、ワールドの広さ、パルワールドでの拠点の大きさや捕まえたパルの数です。XServer GAMEs の記事は、メモリ量を決める要素として人数のほかに、ワールドの内容、描画距離と演算距離、MODやプラグインを挙げています。ロリポップの記事は、パルワールドで拠点が大きい場合はひとつ上のプランを選ぶと安心、と書いています。

## 計算例

ツールの計算ロジックを node で動かして確かめた値です。

**例1：Java版バニラ、8人。** 範囲は 4〜8GB でした。XServer GAMEs の解説記事（5〜10人）が 4GB、ConoHa（5〜10人）が 4GB、XServer GAMEs のプラン表（〜20人）が 8GB です。ロリポップのJava版の表は MOD 使用時の値だけなので、この行は「記載なし」になりました。上限の 8GB を満たす最小のプランは 8GB です。

**例2：Java版バニラ、3人と4人（境界）。** 3人は 2GB だけが並び、最小のプランは 2GB でした（ロリポップのJava版プランは 4GB からなので、ロリポップだけ 4GB が最小になります）。4人にすると範囲が 2〜4GB に広がります。XServer GAMEs の解説記事と ConoHa は「4人以下」で 2GB、XServer GAMEs のプラン表は「〜5人」で 4GB だからです。意外だったのは、同じ4人でも出典によって 2GB と 4GB に分かれたことです。

**例3：パルワールド、4人。** 範囲は 16〜32GB でした。ポケットペアの要件が 16GB（安定運用は 32GB 以上）、XServer GAMEs のプラン表が「〜10人」で 16GB です。ロリポップの表は「2〜3人」の次が「5〜10人」で、4人の行がないため「当たる行がありません」と出ます。上限の 32GB を満たす最小のプランは 32GB です。

**例4：パルワールド、32人（上限）。** 範囲は 16〜128GB でした。ロリポップの「20〜32人」が 128GB、XServer GAMEs のプラン表が 32〜64GB です。128GB 以上のプランがあったのはロリポップだけで、XServer GAMEs と ConoHa の掲載プランは 64GB までなので「届きません」と表示されました。33人以上を入れると、数字は出さずに案内だけを出します。

## よくある間違い

**Java版の -Xmx を、プランのメモリいっぱいにする。** 8GB のサーバーなら 8G を指定したくなりますよね。XServer GAMEs の解説記事にあるメモリ割り当ての表では、プランが 2GB なら 1000、4GB なら 3000、8GB なら 7000 と、プランの容量より少し小さい値が示されています。理由までは記事に書かれていませんが、容量ちょうどを割り当てる形にはなっていません。

**統合版とJava版の目安を混ぜる。** ロリポップの表では、6〜10人の目安が統合版で 4GB、MOD を使うJava版で 8GB と別々に載っています。XServer GAMEs の解説記事は、基本的に統合版のサーバーではメモリ割り当てができないとも書いています。どちらの表を見ているのか、ゲームの種類を先に決めてから数字を読んでください。

**MODの数だけでメモリが決まると思う。** 確かめたかぎり、MODの個数からGB数を示した出典はありませんでした。大型のMOD（工業系・魔術系）は 4GB でも足りないことがある、という注意書きがあるだけです。人数、ワールドの内容、描画距離のほうも効きます。

## よくある質問

### Q. 友達4人でマイクラをやるなら、何GBですか？
A. Java版バニラで4人と入れると、2〜4GB と出ました。出典によって「4人以下は 2GB」と「〜5人は 4GB」に分かれます。余裕を見たいときは、上限側の 4GB を基準にしてください。

### Q. パルワールドは 8GB では足りませんか？
A. ポケットペアの要件ページには、メモリは 16GB、安定した動作のためには 32GB 以上を推奨、と書かれています。8GB という数字は、現在の要件ページでは確認できませんでした。

### Q. サービスによって数字が違うのはなぜですか？
A. 出典ごとに人数の区切り方が違うためです。「4人以下」「〜5人」「10人〜」のように、境界の書き方もそろっていません。ツールは食い違いをそのまま表に残し、最小値と最大値の範囲を出しています。

### Q. 表示されたプランは、今も申し込めますか？
A. プランの構成や新規受付は変わります。表示するのはプランのメモリ容量だけで、料金や受付状況は載せていません。申し込む前に、各社の公式ページで確認してください。
