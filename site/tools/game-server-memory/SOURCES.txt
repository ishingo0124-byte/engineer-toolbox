- ConoHa for GAME top/pricing pages show a banner "臨時メンテナンスのため、新規お申し込み受付を停止" while the news list also has a "受付再開のお知らせ" item. The state is contradictory, so the tool does NOT state it; it only says "新規受付の状況は変わります。申し込み前に公式ページで確認".
