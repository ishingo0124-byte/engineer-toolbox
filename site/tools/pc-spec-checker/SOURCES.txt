Ollama RAM guidance
  - Current ollama/ollama README.md (main) has NO RAM statement (checked). docs.ollama.com FAQ / Windows / Quickstart / Hardware support have no 7B/13B/33B figure.
  - Model page "llama2": "7b ... at least 8GB of RAM", "13b ... at least 16GB", "70b ... at least 64GB"
    https://ollama.com/library/llama2
  - README at tag v0.3.0, Model library note: "at least 8 GB of RAM to run the 7B models, 16 GB to run the 13B models, and 32 GB to run the 33B models"
    https://raw.githubusercontent.com/ollama/ollama/v0.3.0/README.md
  - Windows OS requirement: Windows 10 22H2 or newer, Home or Pro. Page: "Windows" (Ollama docs)
    https://docs.ollama.com/windows
  - Quickstart (VRAM note: with less VRAM Ollama can use system RAM but responses may be slower)
    https://docs.ollama.com/quickstart
