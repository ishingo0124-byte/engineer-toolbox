`<` を書いたらタグとして消えた。
`&amp;amp;` と表示されてしまい、どこで二重になったのか分からない。
`&#65;` と書かれた文字が、何なのか読めない。
このツールは、テキストと HTML 実体参照（`&lt;`、`&amp;`、`&#65;` など）を両方向に変換します。テキスト用と属性値用の切り替えもできます。

## 使い方

1. 上の「テキスト」欄に文章を入れると、下の「HTML実体参照」欄にエスケープ結果が出ます。入力のたびに自動で更新されます。結果はコピーボタンで取れます。
2. 逆向きも同じ画面でできます。実体参照を含む文字列を下の欄に貼ると、デコードした結果が上の欄に入ります。下の欄を書き換えると上の欄が上書きされるので、手で直した文章を残したいときは先にコピーしておいてください。
3. 属性値（`value="..."` や `title='...'` の中）に埋め込むときは、「属性値用」を選びます。`"` と `'` もエスケープされます。

「クリア」を押すと、両方の欄が空になります。

## 仕組み・計算式

HTML Living Standard（WHATWG）は、本文中の `<` をタグの始まりとして、`&` を文字参照の始まりとして読む、と定めています。文字として表示したいなら、文字参照に置き換えます。このツールがエスケープするのは次のとおりです。

- テキスト用:`&` は `&amp;`、`<` は `&lt;`、`>` は `&gt;`
- 属性値用:上の3つに加えて、`"` は `&quot;`、`'` は `&#39;`

変換は `&` を最初に行います。順番を逆にすると、先に作った `&lt;` の `&` がもう一度変換されてしまいます。日本語や絵文字は、そのまま残します。

デコードは、名前つきの参照（`&copy;`、`&eacute;`、`&hellip;` など74種類）と、数値の参照（10進の `&#65;`、16進の `&#x41;`）に対応しています。HTML Living Standard の名前つき参照は2,000を超えるので、ここに入っていないものは読めません。読めなかったものは原文のまま残し、件数と名前を下に出します。デコードは1回だけです。

エスケープは、HTML の中に文字として安全に出すための処理です。XSS 対策のすべてではありません。`<script>` の中、`onclick="..."` のようなイベント属性、URL のクエリ、CSS の値では、それぞれ別の扱いが要ります。URL のクエリなら RFC 3986 のパーセントエンコードです。

## 計算例

ツールの script.js を node で動かして確かめた値です。

**例1:テキスト用と属性値用の違い。** `<a href="x.php?a=1&b=2" title='hi'>5 > 3</a>` を入れます。テキスト用は `&lt;a href="x.php?a=1&amp;b=2" title='hi'&gt;5 &gt; 3&lt;/a&gt;` でした。属性値用だと `&lt;a href=&quot;x.php?a=1&amp;b=2&quot; title=&#39;hi&#39;&gt;5 &gt; 3&lt;/a&gt;` になります。引用符の部分だけが違います。

**例2:デコード。** 下の欄に `&lt;p&gt;caf&eacute; &copy; &#65;&#x42; &#x1F600; &amp;lt; &foo;` を貼ると、上は `<p>café © AB 😀 &lt; &foo;` になりました。`&amp;lt;` は1回だけ戻るので `&lt;` で止まります。`&foo;` は未対応として残り、「未対応の実体参照 1 件」と出ます。

**例3:境界と二重エスケープ。** `Tom & Jerry` は `Tom &amp; Jerry` です。この結果をもう一度上の欄に入れると `Tom &amp;amp; Jerry` になりました。セミコロンのない `&amp` は、デコードしても `&amp` のままです。`&#1114112;`（U+10FFFF を超える値）と、大文字小文字が違う `&Copy;` も、そのまま残りました。

## よくある間違い

**保存前にエスケープして、表示でもう一度エスケープする。** データベースに `&amp;` が入っていると、画面には `&amp;` と見えます。エスケープは、HTML に出す直前に1回だけです。画面に &amp;amp; が見えたとき、どこで1回余計にエスケープしたか、思い当たりませんか。例3のように、二重になった文字を見たらここを疑います。

**HTML 用の結果を JavaScript や URL にも使う。** `onclick="f('...')"` の中は、ブラウザが先に HTML としてデコードしてから JavaScript として読みます。HTML エスケープだけでは足りません。URL に入れるなら、別のエンコードが要ります。

**`&#150;` のような古い数値参照を、そのまま信じる。** ブラウザの HTML パーサは、128〜159番の数値参照を Windows-1252 の文字に読み替えます。このツールは番号どおりの制御文字に変えます。古いページの文字化けを直すときは、結果が表示と一致するか目で見てください。意外だったのは、&#150; を入れると見えない制御文字（U+0096）が返ってくることでした。

## よくある質問

### Q. `&apos;` と `&#39;` はどちらを使えばいいですか。
A. `&apos;` は HTML5 では有効ですが、HTML4 や古いメールクライアントでは読めないことがあります。このツールが出すのは `&#39;` です。どちらもデコードはできます。

### Q. `>` はエスケープしなくてもいいのでは?
A. テキストの中の `>` 単体は、構文の上では必須ではありません。ただ、`<` とそろえて変換しておくと、あとで見直すときに迷いません。このツールは常に変換します。

### Q. 日本語がそのまま出てくるのはなぜですか。
A. HTML ファイルの文字コードが UTF-8 なら、日本語はエスケープなしで書けます。変換が要るのは `&`、`<`、`>`、引用符の5文字だけです。

### Q. セミコロンを書き忘れた `&copy 2026` は読めますか。
A. このツールでは読めず、そのまま残ります。ブラウザは一部の古い参照だけセミコロンなしでも読みますが、書き手としては必ず `;` まで書いてください。
