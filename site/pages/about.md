# このサイトについて
description: エンジニアの道具箱は、インフラ・開発の現場で毎日使う計算・変換ツールを、登録なし・ブラウザ内処理で提供する無料ツール集です。

「エンジニアの道具箱」は、サーバー・ネットワーク・開発の現場で繰り返し使う小さな計算や変換を、**開いてすぐ使える**形でまとめた無料ツール集です。現在 {{tool_count}} 個のツールを公開しています。

## 方針

- **登録なし・無料**。すべてのツールはブラウザ内（JavaScript）だけで動き、入力した内容はサーバーへ送信されません。IPアドレスや設定値など、業務上の情報をそのまま貼り付けても外に出ません。
- **正確さを優先**。計算式や仕様は RFC・POSIX・公式ドキュメントなどの一次情報にもとづき、各ツールの解説に根拠を書いています。境界値（/31 や /32、うるう年、タイムゾーン）の扱いも明記します。
- **広告は控えめ**。運営費は広告と一部のアフィリエイトリンク（PR 表記あり）でまかないます。ツールの動作や結果に広告が影響することはありません。

## 免責

各ツールは十分に検証していますが、結果の正確性を保証するものではありません。本番環境へ適用する前には必ずご自身で確認してください。本サイトの利用によって生じたいかなる損害についても、運営者は責任を負いかねます。

## 誤り・要望

計算結果の誤りや「こんなツールが欲しい」は、[GitHub の Issues](https://github.com/ishingo0124-byte/engineer-toolbox/issues) からお知らせください。誤りの指摘は優先して対応します。
