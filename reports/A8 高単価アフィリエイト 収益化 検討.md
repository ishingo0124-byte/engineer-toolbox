# A8の高単価は、流入の隣にだけ置く

A8.net の高単価案件で収益を上げる方法は、単価の高い案件を探すことではありません。いまある検索流入の「次の手続き」に合う案件を少数だけ選び、規約と法令に沿って置くことです。工房のサイトは自然検索が週35セッション前後、28日間のアフィリエイトのクリックが2回で、収益は0円です。単価1万円の案件に差し替えても、期待値は月160円ほどにしかなりません（推定）。合う場所は三つに絞れます。最大の流入ページである学歴早見表（履歴書を書く人）には転職・就活エージェントの面談型（A8 の公開ランキングで1件¥7,875〜18,000）、インフラ系のページには IT エンジニア向けの転職、11月に公開する相続のページには不動産の売却査定（同じく1件¥30,000の例）です。美容医療・カードローン・債務整理・保険商品の比較・FX や暗号資産は単価が高くても、医療広告等ガイドライン・貸金業法・弁護士法・保険業法・金商法が先に扉を閉めていて、工房の流入ともつながりません。X は、アフィリエイトの販路としては使わないことを勧めます。「高単価アフィリ」を掲げる投稿の多くは情報商材の入口で反応は0〜1件、実測の成約データは見つからず、自動投稿は X の規約で厳しく縛られています。作業の大半（ページ、枠の割り当て、規約の自動点検、集計）は Claude Code が担えます。オーナーに残るのは A8 管理画面での確認と提携申請、月1回のレポート CSV のダウンロード、デプロイの承認で、90日の合計は1時間半ほどです（推定）。見込みは90日後で月¥0〜1,000、6か月後の基本線で月1万円弱（推定）で、本社の見通しと同じ帯に入ります。最初にやるのは、既存の A8 枠の規約対応（テキスト素材の文言、本文リンクの PR 表記、ページ冒頭の PR 表記）です。

証拠の種類は、本文で次のように分けます。【実測】は計測・調査の数字、【自己申告】は個人の未検証の報告、【宣伝】は教材・note・セミナーへの誘導を伴う投稿、【推定】は私の仮定と計算です。

## 週35セッションでは、単価を10倍にしても収益は0円のまま

工房のサイトは93ツールを公開し、Search Console の表示回数は28日間で3,720回まで伸びました。それでもクリックは47回で、直近7日の CTR は0.7〜0.8%です。GA4 の自然検索は週56→36→33→35セッションと横ばいから減り気味で、28日間の外部リンクのクリックは2回、収益は全期間0円です。AdSense は2026年10月5日に「有用性の低いコンテンツ」で不承認になりました（`data/kpi.csv` の10/12・10/14の記録）【実測】。A8 の枠は、インフラ系21ページ（VPS 17、Web 4）に XServer VPS・ConoHa VPS・ConoHa WING・さくらのVPS の4案件があるだけです（`site/data/a8.json`）。**表示回数の約43%（3,720回のうち1,588回）を占める学歴早見表（school-year-table）には A8 の枠がなく**、楽天のランドセル・入学祝いの検索リンクが出ています（`site/data/rakuten.json`）。この解説は「履歴書の学歴欄」から書き始めているので、読者の目的と枠の中身がずれています。

数字で見ると、単価の問題ではないことがはっきりします。単価1万円、クリックから成果が発生する割合を1%、承認率を80%と置くと、**月2クリックの期待値は月160円で、成果1件は約4年に1回のペース**です【推定】。収益は「クリック数×成果発生率×承認率×単価」の掛け算なので、単価を10倍にしても、ほかの項がほぼ0なら結果もほぼ0のままです。動かせるのは、枠を見る人数と、枠が読者の次の一手に合っている度合いの二つだけです。

業界の分布も同じことを示しています。JAO の2025年調査（アフィリエイト広告を載せている1,000人のパネル）では、**月1,000円未満が52.5%、月3万円以上は12.4%**でした ([JAO アフィリエイト市場調査2025](https://www.japan-affiliate.org/news/survey2025/))。ASP 会員向けの協会調査2026（n=991）でも月1万円未満が52.8%です。月100万円以上の19.2%は法人と長期運営者に偏っていて、**月500万円以上の78.4%は1日3時間以上作業**しています。協会自身が「不労所得のような形で高収入になるケースはほとんど無く」とまとめています ([アフィリエイトマーケティング協会 意識調査2026](https://affiliate-marketing.jp/release/202606.pdf))【実測。ただし熱心な層に偏ったサンプル】。オーナーの手をほぼ使わない運営は、この分布の下半分から始まると見るのが正直です。本社の見通し（6か月で月¥1,000〜1万）はこの位置と合っています。

A8 そのものの性格も計画に入れておきます。A8 は協会調査で16年連続の満足度1位ですが、選ばれた理由は「広告数が多い」が49.9%で、「報酬単価が高い」は11.0%です。レントラックス（39.2%）や Felmat（39.6%）を大きく下回ります。特別単価は専属担当を通じた交渉で決まり、回答者の約6割にはまだ担当が付いていません ([意識調査2026](https://affiliate-marketing.jp/release/202606.pdf))。成果ゼロの段階で特単を当てにした計画は立てられません。A8 は案件の幅と入口として使い、成果が出た案件だけ他の ASP と単価を比べる順番にします【推定】。

検索の環境は、記事で集めて申込に流す型に逆風です。Ahrefs の計測では、日本の情報収集型キーワードで AI による概要が出ると、**検索1位の CTR が予測24.1%に対して実測9.0%（−62.7%、2026年6月）**でした ([Ahrefs](https://ahrefs.com/ja/blog/ai-overviews-reduce-clicks-june-2026/))。作業が完結するツールは要約で置き換えにくいので、工房の型はこの点で有利です（推定）。ただし単純な換算ほど AI がその場で答えるので、有利さは計算の重さに比例します。

いちばん筋が良いのは、既存の最大流入をそのまま使える転職・就活です。ただし公開ランキングに出ている転職案件は、エンジニア・コンサル・メーカー向けが中心です。学歴早見表に来る学生・若手・アルバイト経験者に合う一般向けや新卒向けの案件は、管理画面で探すしかありません。これが後で示すチェック表の最初の項目です。成果地点が「面談の実施」と重いので、表示上の単価をそのまま見込みに使わないことも大事です。

合うジャンルにも守る線があります。転職では、職業安定法で届出が要るのは求職者の情報を集めて提供する「特定募集情報等提供事業」で、紹介会社のページへリンクで送客するだけなら通常は届出不要と読めます（アフィリエイトを名指しした Q&A はなく、推定）。「年収診断」のように氏名や職歴を集めて渡すツールは届出の対象になり得るので作りません。求人の給与などを転載・要約すると、5条の4（虚偽・誤解を生じさせる表示の禁止）の論点も出ます ([厚労省 令和4年改正職業安定法Q&A](https://www.mhlw.go.jp/content/001250191.pdf))。不動産では、宅建業法32条の誇大広告の禁止と表示規約の名宛人は業者ですが、個別の物件情報を載せない、「必ず高く売れる」と断定しない、の二つは守ります ([e-Gov 宅地建物取引業法](https://laws.e-gov.go.jp/law/327AC1000000176))。相続で次に出てくる士業の紹介は置きません。弁護士は依頼者の紹介に対価を払えず（弁護士職務基本規程13条） ([法務省掲載の規程](https://www.moj.go.jp/content/001329720.pdf))、税理士・司法書士の紹介料の規律は今回の調査で一次資料を確認できていないからです。

10月に出す特定親族特別控除・年収の壁・最低賃金のページに高単価枠を置かないのには、二つの理由があります。転職への筋道が検索に見えないことと、12月の AdSense 再申請の前に「計算が完結する、広告の少ないページ」を増やしておきたいことです（後者は推定）。保険の無料相談（保険マンモス ¥13,745、ガーデン ¥10,250） ([A8 報酬UPプログラム](https://support.a8.net/as/HintOfProgram/pickup/up.php)、[A8 今月のおすすめ](https://support.a8.net/as/HintOfProgram/month_collection.php)) は、「生命保険料控除 計算」のページを将来作ったときだけ候補にします。その場合も相談サービスの紹介にとどめ、保険商品の比較は書きません（次節）。

## 医療・借入・債務整理・保険商品・投機は、法律が先に扉を閉めている

三つの適合先の外にある高単価案件は、規制がアフィリエイター自身の文章に直接かかるか、広告主側の規律で小さなサイトの書ける中身がほとんど残らないジャンルです。しかも、どれも工房の流入とつながりません。

罰の降りかたも押さえておきます。消費者庁の Q&A では、アフィリエイターはステマ規制の対象外が原則です ([消費者庁 ステマQ&A](https://www.caa.go.jp/policies/policy/representation/fair_labeling/faq/stealth_marketing/))。実際のリスクは契約の側にあります。A8 は2026年9月1日改訂の規約で PR 表記を会員の義務にしていて、違反すれば強制退会、未払い報酬の没収、既払い分の返還請求まであり得ます ([A8 メディア会員利用規約](https://www.a8.net/compliance/media-userpolicy.php))。広告主も、PR 表記がないメディアの提携解除や成果のキャンセルができます ([A8 PR等の表記](https://www.a8.net/compliance/prNotation-urlSubmission.php))。2024年10月施行の改正景表法で広告主の側のリスク（直罰・課徴金の割増し）が上がったので、審査は厳しくなる方向です ([BUSINESS LAWYERS](https://www.businesslawyers.jp/articles/1312))。直罰がアフィリエイターにも及ぶとする解説もありますが、公式見解は見つかっていません。

## X はアフィリエイトの販路にならず、自動化は凍結の近道になる

## 収益の見込み：6か月後の基本線で月1万円弱（推定）

見込みは五つの数字の掛け算で作ります。月間セッションは、現状が約150（週35×約4.3）【実測】、6か月後は本社の見通し（月1万〜3万 PV）に合わせました。枠のクリック率は、いまのサイト全体で約1.3%（月150セッションで2クリック）なので、1〜3%と置きます。成果発生率（クリックから面談・申込まで）は、検証できる公開データが見つかりませんでした。X の試算が置いた2%は本人の仮定です。ツールの利用者は目的を果たした直後なので比較記事の読者より低いと見て、0.5〜1.5%と置きます。承認率は、ブログが A8 全体の平均として引用した68〜100% ([Stillworks Lab](https://stillworks-lab.hatenablog.com/entry/2026/06/09/144058)) から70〜80%に、平均単価は転職（¥7,875〜18,000）・不動産査定（¥30,000）・VPS（数千円と推定）の混合で¥10,000〜12,000にしました。

すべて【推定】です。読み方の注意が三つあります。一つ目に、基本線でも承認件数の期待値は月0.9件なので、**ポアソン分布で計算すると約4割の月は承認される成果が0件**です。月ごとの数字は大きくぶれます。二つ目に、上振れはすべての仮定が楽観側にそろった場合で、本社の12か月の見通し（月¥1〜5万）の上端にあたります。月100万円は、どの組み合わせでも届きません。三つ目に、現金になるのは遅れます。A8 の支払いは月末締め・翌々月15日払いで、繰越が1,000円以上になると振り込まれます ([A8 FAQ 支払条件](https://support.a8.net/a8/as/faq/2008/08/post_166.html))。面談型は確定までの日数も読めないので、最初の入金は早くて2027年3〜5月と見ています（推定）。振込手数料はメディアの負担で、3万円未満なら他行口座は495円、ゆうちょ口座は66円です ([A8 FAQ 振込手数料](https://support.a8.net/a8/as/faq/2008/05/as_3.html))。給与所得者で給与以外の所得が年20万円以下なら所得税の確定申告は不要です（還付申告などの例外あり、住民税は別） ([国税庁 No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm))。

この表からわかることがあります。上振れと下振れの差は約100倍ですが、その内訳はセッション数・枠が出る割合・クリック率で約24倍、成果発生率で3倍、承認率と単価は合わせて1.4倍ほどです。単価はほとんど効いていません。だから、90日間の作業の配分は「流入を増やすツール」が主、「枠の置き場所」が従のままにします。置き場所はクリック率と成果発生率の両方に効くので、従とはいえ手間に対する効きは大きい作業です（推定）。

## 結論

ツールサイトにとって「高単価」は、案件選びの問題ではなく置き場所の問題です。1件の単価は広告主が決めますが、サイトが決められるのは、読者の作業が終わり、次のお金のかかる手続きが始まるちょうどその場所に枠があるかどうかだけです。工房では、それが「履歴書の学歴欄を書き終えた人」と「相続人と相続分を確かめ終えた人」でした。単価表を上から眺めて見つかる場所ではなく、自分のページの解説の一行目から見えてくる場所です。

もう一つ見えたのは、規制の地図と工房の強みが重なっていることです。体験談やランキングが禁じられているジャンル（医療・借入・債務整理）は、工房に流入がないジャンルでもあります。適合する転職・不動産査定は、規律の名宛人が主に広告主の側にあるので、工房の仕事は「言い過ぎないこと」と「個人情報を集めないこと」に絞れます。どちらも、根拠・確認日つきで外に送らないという工房の型が、もともと守っていることです。90日の本当の成果は月数百円の報酬ではなく、ページ別・案件別のクリックと発生の表です。どのクラスタでお金が動くかを自社の数字で示すこの表は、段2の有料版の題材選びにもそのまま使えます。

## やらない手法（早見表）

| 手法 | よく見る主張 | やらない理由 |
|---|---|---|
| AI で「おすすめ転職エージェント」「一括査定ランキング」の記事を量産する | 「AI で記事を量産して放置」 | Google は価値を足さない量産（scaled content abuse）と薄いアフィリエイト（thin affiliation）をスパムとする ([Google スパムポリシー](https://developers.google.com/search/docs/essentials/spam-policies))。2026年はスパムアップデートが4回 ([Google 検索ステータス](https://status.search.google.com/products/rGHU1u87FJnkP6W2GwMi/history))。1位の80.5%は人間の文章 ([Semrush](https://www.semrush.com/blog/does-ai-content-rank-in-search-data-study/))。A8 も根拠のないランキングを禁じる ([A8 NG事例集](https://www.a8.net/compliance/media-ng.php)) |
| X でアフィリエイトリンク付きの自動返信・自動投稿をする（ブラウザ操作を含む） | 「ChatGPT で投稿してプロフで待つ」 | ランダムな投稿への自動返信は禁止、AI の返信は事前承認制、API 以外の自動化は永久凍結 ([X Developer Guidelines](https://docs.x.com/developer-guidelines))。成約の実測データもない |
| セルフバックを他人に勧める（とくに借入と組み合わせる） | 「借金がある人ほどセルフバックを」 | セルフバックは本人が使う予定のあるサービスだけで、代理申込・他人名義は禁止 ([A8 セルフバックの注意事項](https://support.a8.net/as/caution.html))。借入と組んだ勧誘の被害者を弁護士が探している投稿もある ([Yahoo!リアルタイム検索「セルフバック」](https://search.yahoo.co.jp/realtime/search?p=%E3%82%BB%E3%83%AB%E3%83%95%E3%83%90%E3%83%83%E3%82%AF)) |
| 債務整理・過払い金の相談へ送客する | 「1件1万円」 | 弁護士法72条・職務基本規程13条、日弁連の業務広告指針の改正（2026年4月1日施行） |
| 美容医療・脱毛で体験談やビフォーアフター、ランキングを書く | 「私も受けましたがおすすめ」 | 医療広告等ガイドラインがアフィリエイターを名指しで対象にし、体験談は不可 ([厚労省](https://www.mhlw.go.jp/content/001683594.pdf)) |
| 報酬額や成果条件をページや公開リポジトリに書く | 「報酬〇円の案件」 | A8 の会員限定情報の公開禁止 ([A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php)) |
| 「年収診断」などで氏名・職歴を集めて紹介会社へ渡す | 「診断でリードを取る」 | 職業安定法の特定募集情報等提供事業（届出）に当たり得る ([厚労省 Q&A](https://www.mhlw.go.jp/content/001250191.pdf))。サイトの「外に送らない」約束にも反する |
| 提携申請をまとめて大量に出す、計測用リンクを自動でたたく | — | 無差別な大量申請と、ボットによるクリックは禁止 ([A8 禁止事項](https://www.a8.net/compliance/prohibited-matter.php)) |
